# 數位精忠里 / Digital Jingzhong

靜態響應式社區資訊網站，適用於 GitHub Pages。

- 繁體中文（預設）、英文、日文、德文、法文、越南文
- 十五項政見，依主題分類
- 無需 npm / Node.js 或建置工具
- 友善高齡閱讀的字級、鍵盤操作及縮減動態效果

## 部署

將本資料夾內容（`index.html`, `assets/`, `README.md`, `.nojekyll`）上傳到 GitHub Repository `jingzhong-community/jingzhong-community.github.io` 的 `main` 分支。

GitHub Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save。

網址：https://jingzhong-community.github.io/

## 維護方式

介面翻譯存於 `assets/app.js` 的 `UI`，十五項政策資料存於 `RAW`。政策內容更新時，請同步檢查六種語言版本。

注意：網站政策文字為候選人主張與提案的資訊摘要，非政府核定計畫；部分政策在既有文宣中有重疊，正式發布前請確認。
